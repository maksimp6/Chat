# Support

## Before opening a request

Check the README, documentation, existing Issues, and recent PRs first.

For reproducible bugs, include the app/runtime version or commit, platform, exact steps, expected behavior, actual behavior, and relevant sanitized logs.

Do not paste API keys, tokens, passwords, private URLs, database credentials, or personal data.

## Where to ask

- **Bug:** use the Bug Report issue template.
- **Feature:** use the Feature Request template.
- **Documentation problem:** use the Documentation template.
- **Security issue:** follow SECURITY.md and use a private report.
- **General discussion:** use GitHub Discussions when enabled for the repository.

The project is actively evolving. Features marked experimental may change without backward compatibility.
