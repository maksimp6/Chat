Эти механизмы реализованы в репозитории. Для работы нужен собственный запуск и настройка провайдера и инструментов.

01 / AI

Диалог с моделью

Основной путь чата использует Yandex AI Studio Responses API. Доступ к провайдеру настраивается в приложении.

02 / Tools

MCP и локальные инструменты

Единый механизм выполнения связывает вызовы инструментов с запросом и его контекстом.

03 / Trace

История каждого выполнения

Execution Trace связывает запросы, вызовы инструментов, ошибки, время и данные учёта использования.

04 / Android

Клиент для разработки

Android WebView-клиент включает диагностику и путь сборки debug APK. Он предназначен для разработки и тестирования.

About the project

Alice Pro, an open-source AI assistant platform.

Alice Pro is a self-hosted AI assistant platform built around Yandex AI Studio, MCP and local tools, execution traces, usage accounting, and an Android WebView debug client. It is intended for developers and people exploring their own AI assistant setup.

The project is under active development. Public production deployment is not verified, and the Android debug build is for development and testing, not a stable release. Source code is available under the MIT License.
