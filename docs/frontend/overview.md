# Структура интерфейса

Описание архитектуры фронтенд-части приложения: компоненты, маршрутизация, управление состоянием и взаимодействие с бэкендом.

## Локальные ресурсы

Все ресурсы веб-интерфейса Logos должны храниться в репозитории и загружаться по локальным путям. Это относится к JavaScript, CSS, шрифтам, иконкам, изображениям и отладочным библиотекам.

Не подключайте CDN, удалённые stylesheet/script URL или другие внешние asset URL в пользовательском интерфейсе. В частности, favicon должен загружаться из `/static/favicon.svg`.

Для этого правила предусмотрен регрессионный тест `tests/test_local_web_assets.py`, которого в репозитории пока нет.
