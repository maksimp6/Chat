# Локальные веб-ресурсы

Все обязательные ресурсы интерфейса Alice Pro должны храниться в репозитории и загружаться локально. Нельзя добавлять обязательные зависимости от CDN или удалённых URL для JavaScript, CSS, шрифтов, иконок, favicon и других UI-ресурсов.

Сетевые URL допускаются для API-интеграций и пользовательских данных, но не для загрузки самого интерфейса.

## Eruda

Eruda 3.4.3 хранится в `static/vendor/eruda.min.js`. Панель подключается локальным скриптом и включается через `?debug=1`, `#debug` или сохранённый флаг `alice-eruda-enabled`. Для отключения используется `?debug=0`.

Копия MIT-лицензии хранится в `static/vendor/eruda.LICENSE`.
