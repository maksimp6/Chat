# Интеграционный контур Logos

Публикацию и проверки определяют [AGENTS.md](../../AGENTS.md) и последнее
прямое поручение владельца. База интеграции — текущий `develop`;
`master` является личной веткой владельца.

Старый список кандидатов от 27 сентября и базовый SHA из `master` исключены
из текущего реестра. Состав работ устанавливают актуальные Issues/PR после чтения
их HEAD, истории и критериев; старый номер задачи сам по себе не задаёт очередь.

Kristall используется серверными repositories для conversations, configuration,
sessions, invocations, traces и других префиксов из контракта хранилища.
Миграция существующих исторических данных и приёмка конкретного развёртывания
требуют отдельных доказательств и не следуют автоматически из наличия backend.

Для каждой активной работы укажите одного основного исполнителя, зависимости,
исходный SHA, результат, ссылки на материалы и границу проверки. Пересекающиеся
реализации согласуйте в существующем Issue/PR. Этот реестр не подтверждает
исправление или закрытие перечисленных задач.
