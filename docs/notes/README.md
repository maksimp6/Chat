# Конспекты внешней документации

`docs/notes/` хранит переработанные человеком или AI конспекты внешних источников, написанные нашими словами и адаптированные под Alice Pro.

Это не архив и не зеркало исходной документации.

## Назначение

Конспекты нужны, чтобы агент сначала читал короткое, проектно-ориентированное объяснение, а уже затем при необходимости обращался к сырому зеркалу или live-документации.

Рекомендуемый порядок чтения:

```text
вопрос
  ↓
docs/notes/
  ↓
docs/mirrors/ при необходимости точных деталей
  ↓
live official docs при необходимости актуальной проверки
```

## Правила

- можно пересказывать и сокращать исходную документацию;
- можно добавлять выводы, риски, рекомендации и привязку к Alice Pro;
- обязательно указывать исходные официальные URL или ссылки на соответствующий mirror manifest;
- явно отделять факт из источника от нашего проектного решения;
- не считать конспект канонической копией внешнего источника;
- при быстро меняющихся данных проверять live-источник.

## Структура

```text
docs/notes/
├── README.md
├── cloudru/
├── yandex-ai-studio/
├── openai/
├── github/
└── ...
```

Каждый источник может иметь собственный `README.md` и тематические файлы.
