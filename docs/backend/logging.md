# Система логирования Alice Pro

## Структура логов

Все логи хранятся в папке `logs/` и автоматически ротируются по размеру (5 MB) с тремя резервными копиями.

## Таблица логов и их назначение

| Лог‑файл | Что искать | Ключевые функции |
|----------|-----------|----------------|
| `app.txt` | Общие ошибки Flask, старт/стоп приложения, системные сообщения | `log_app()` |
| `api_debug.txt` | Запросы и ответы к Yandex AI Studio, ошибки API | `log_api()` |
| `voice.txt` | Голосовые команды, ошибки распознавания, статус микрофона | `log_voice()` |
| `chat.txt` | Сообщения чата, обработка Markdown, ошибки отображения | `log_chat()` |
| `database.txt` | Запросы к SQLite, миграции, ошибки базы данных | `log_db()` |
| `errors.txt` | Исключения Python, критические ошибки | `log_error()` |
| `search.txt` | Запросы поиска, результаты, ошибки индексации | `log_search()` |
| `prompts.txt` | Системные промпты, их отправка и ответы | `log_prompt()` |
| `stats.txt` | Статистика использования, время ответов, нагрузка | `log_stats()` |
| `export.txt` | Операции экспорта данных, ошибки сохранения | `log_export()` |

## Настройка логирования

Параметры логирования задаются в `logger.py`:

* **Максимальный размер файла**: 5 MB;
* **Количество резервных копий**: 3;
* **Формат даты**: ISO 8601;
* **Уровень логирования**: DEBUG (по умолчанию).

## Поиск ошибок по логам

**Пример сценария:** пользователь жалуется на проблемы с чатом.

1. Проверьте `chat.txt` — ошибки обработки сообщений.
2. Проверьте `errors.txt` — критические ошибки.
3. Проверьте `api_debug.txt` — ответы от Yandex AI Studio.
4. Проверьте `app.txt` — системные ошибки Flask.

## Рекомендации по отладке

1. **Проблемы с чатом**:
   * проверьте `chat.txt` на ошибки Markdown;
   * проверьте `api_debug.txt` на ответы от AI;
   * проверьте `errors.txt` на исключения.

2. **Проблемы с голосом**:
   * проверьте `voice.txt` на ошибки микрофона;
   * проверьте разрешения Termux;
   * проверьте `errors.txt`.

3. **Проблемы с базой данных**:
   * проверьте `database.txt` на ошибки SQLite;
   * проверьте `errors.txt` на исключения.

## Важные замечания

* **Ротация логов**: файлы автоматически сжимаются в `.gz` после достижения лимита.
* **Очистка логов**: для очистки старых логов используйте:

```bash
rm logs/*.gz
```

* **Мониторинг в реальном времени**: для просмотра логов в реальном времени используйте:

```bash
tail -f logs/app.txt
```
