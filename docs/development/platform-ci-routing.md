# Проверки изменённых областей

Прежняя матрица обязательных платформенных jobs снята с текущего процесса.
Описание PostgreSQL и Android APK lanes удалено.

[AGENTS.md](../../AGENTS.md) определяет, когда и где разрешён запуск тестов.
При отдельном поручении выберите проверки для изменённого поведения и запишите
их фактический результат. Не запущенные проверки имеют статус `NOT_RUN`.

Публикация и доказательства описаны в [рабочем процессе](../development_workflow.md).
