# Установка системы Alice Pro

## Системные требования

* Android с Termux;
* Python 3.9+;
* доступ к Yandex AI Studio (API‑ключ).

## Расположение проекта

По умолчанию проект располагается в:

```
/sdcard/repo/alice_pro/
```

## Установка зависимостей и запуск

1. Перейдите в директорию проекта:

```bash
cd /sdcard/repo/alice_pro
```

2. Запустите скрипт установки и запуска:

```bash
./start.sh
```

Скрипт автоматически:
* создаст директорию `logs/`;
* проверит наличие зависимостей (`flask`, `requests`, `websockets`);
* установит недостающие зависимости через `pip`;
* запустит приложение командой `python3 app.py`.

## Проверка работоспособности

После запуска откройте в браузере:

```
http://localhost:5000
```

Вы должны увидеть интерфейс Alice Pro с чатом и боковой панелью.

## Ручная установка (альтернативный вариант)

Если скрипт `start.sh` не работает:

1. Установите зависимости вручную:

```bash
pip install flask requests websockets
```

2. Запустите приложение:

```bash
python3 app.py
```

3. Откройте `http://localhost:5000`.

## Настройка API

1. Отредактируйте `config.py`:

```python
YANDEX_API_KEY = "ваш_ключ_от_Yandex_AI_Studio"
```

2. Сохраните файл и перезапустите приложение.

## Ожидаемые результаты установки

После успешной установки:
* создана папка `logs/` с файлами логов;
* приложение доступно по адресу `http://localhost:5000`;
* база данных SQLite создана автоматически;
* все статические файлы загружены из `static/`.
