# Запуск в режиме разработки

## Расположение проекта

Проект разработан для работы в Termux на Android, типичное расположение:

```
/sdcard/repo/alice_pro/
```

## Способы запуска

### Вариант 1: через скрипт запуска (рекомендуется)

```bash
cd /sdcard/repo/alice_pro
./start.sh
```

### Вариант 2: прямой запуск

```bash
cd /sdcard/repo/alice_pro
python3 app.py
```

## Доступ к интерфейсу

После запуска откройте в браузере:

```
http://localhost:5 Hypertext Transfer Protocol5000
```

## Особенности разработки на Termux

1. **Права доступа**: убедитесь, что Termux имеет необходимые разрешения:
   * доступ к хранилищу;
   * разрешение «Поверх других окон» (для фоновой работы).

2. **Обновление кода**:
   * остановите приложение (Ctrl+C);
   * внесите изменения в файлы;
   * перезапустите `./start.sh` или `python3 app.py`.

3. **Отладка**:
   * проверяйте логи в папке `logs/`;
   * используйте консоль Termux для вывода ошибок;
   * для детальной отладки можно добавить `print()`‑выводы в `app.py`.

## Структура папок для разработки

```
alice_pro/
├── app.py                 # Главный файл приложения
├── db.py                  # Работа с SQLite
├── config.py              # Конфигурация
├── logger.py              # Логирование
├── file_routes.py         # Маршруты работы с файлами
├── mcp_routes.py          # Маршруты MCP
├── static/                # Статические файлы (фронтенд)
│   ├── chat.js            # Обработка чата
│   ├── core.js            # Основная логика
│   ├── style.css          # Стили
│   ├── sidebar.js         # Боковая панель
│   ├── models.js          # Работа с моделями
│   └── voice.js           # Голосовые функции
├── logs/                  # Логи приложения
│   ├── app.txt            # Общие ошибки Flask
│   ├── api_debug.txt      # Запросы/ответы Yandex
│   ├── voice.txt          # Голос
│   ├── chat.txt           # Чат
│   ├── database.txt       # SQLite
│   ├── errors.txt         # Исключения
│   ├── search.txt         # Поиск
│   ├── prompts.txt        # Промпты
│   └── stats.txt          # Статистика
└── start.sh               # Скрипт запуска
```

## Проверка работоспособности

После запуска убедитесь, что:
* в консоли Termux нет ошибок;
* приложение отвечает по адресу `http://localhost:5000`;
* в папке `logs/` созданы файлы логов;
* интерфейс загружается полностью (чат, боковая панель и т. д.).
