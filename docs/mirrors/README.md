# Markdown-зеркала внешней документации

`docs/mirrors/` предназначен для максимально близких к источнику Markdown-копий внешней документации.

Mirror не является конспектом. Он не должен переписывать документацию «нашими словами» и не должен обязательным образом прогонять каждую страницу через LLM.

## Назначение

- локальная машиночитаемая копия официальной документации;
- быстрый доступ AI-агентов к точным фрагментам;
- инкрементальное обновление;
- снижение зависимости от доступности внешнего сайта;
- снижение расхода токенов за счёт выборочного чтения.

## Контракт

Каждый provider mirror хранит `manifest.json`, содержащий URL, локальный path, SHA-256, время fetch и статус.

AI-агент сначала читает manifest/index и затем открывает только нужные Markdown-файлы. Полный corpus не загружается в контекст без специальной причины.

## Отличие от notes

`docs/mirrors/` = близкая к источнику копия.

`docs/notes/` = наши выводы, сокращения и адаптация под Alice Pro.

Когда сведения конфликтуют, для факта приоритет имеет официальный live-источник, затем актуальное зеркало, затем конспект.
