# Работа с памятью в Alice Pro

Подсистема памяти отвечает за эффективное хранение, извлечение и управление данными в рамках проекта. Основные компоненты:

- `memory_manager.py` — централизованное управление памятью, координация доступа, очистка устаревших данных.
- `memory_extractor.py` — извлечение данных из памяти, их сериализация и подготовка к использованию в других компонентах системы.

## Архитектура

Компоненты памяти интегрированы в серверную часть (backend) и взаимодействуют с агентами через чётко определённый API. Данные хранятся в оперативной памяти для быстрого доступа, при этом система обеспечивает их целостность и согласованность.

## Сценарии использования

1. **Добавление данных**: агенты или бэкенд вызывают методы `memory_manager` для сохранения данных в памяти.
2. **Извлечение данных**: компоненты, требующие доступа к данным, используют `memory_extractor` для получения информации в нужном формате.
3. **Очистка**: `memory_manager` автоматически удаляет устаревшие данные для оптимизации использования ресурсов.

## Интеграция с другими компонентами

- **Агенты**: используют память для временного хранения контекста диалога.
- **Бэкенд**: сохраняет результаты обработки запросов в памяти для ускорения последующих операций.
- **API**: предоставляет методы для чтения/записи данных через унифицированный интерфейс.
