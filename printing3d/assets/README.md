# Alice Pro — каталог 3D-моделей

Каноническая инвентаризация: [Issue #1112](https://github.com/maksimp6/Chat/issues/1112).
Машинный каталог: [catalog.json](catalog.json). **Ни этот каталог, ни 3MF с геометрией не запускают печать.**

## Уже сохранено в этом PR

- `parametric/phone_stand.scad` — параметрическая подставка телефона.
- `parametric/sauce_stand.scad` — подставка для соусов.
- `parametric/test_tube_holder.scad` — параметрический держатель пробирки.
- `parametric/test_tube_holder.3mf` — однопластинная **ненарезанная** геометрия (один объект, 481 вершина, 958 треугольников; ZIP CRC проверен).

Файлы переносились из пользовательского Google Drive побайтово. Их SHA-256 записаны в каталоге; исходники **не отформатированы и не изменены**. Предварительные размеры в CAD не означают проверку посадки, механической прочности или безопасности.

## Что не дублируем

- [PR #1110](https://github.com/maksimp6/Chat/pull/1110) уже содержит отдельную OEM-модель `.3mf` для A1 mini; этот PR не копирует тот же бинарный файл. Нужны реальные измерения заводского штока.
- Архивы PETG держателей, OEM CAD/STEP и прототипы хранятся в исходных источниках; перечислены по имени и SHA-256 в `catalog.json`. Содержимое архива **не приравнивается** к готовому одному файлу печати. В исходном OEM ZIP находятся `.py`, `.step` и `.stl`; сохранение полного оригинального набора и проверка воспроизводимости — отдельный шаг по #1112.
- Valve/Dota / Ember Spirit и `.blend`-прототипы остаются **вне публичного GitHub** до проверки прав на распространение и технического качества.
- Готовый sliced `.gcode.3mf` тестового куба существует как проверяемый внешний артефакт PR #1101, но его не добавляем в каталог исходников как якобы готовый продукт.
- Источники: пользовательский Google Drive «3D Models», «3D модели» и ChatGPT Library. Не публикуем ссылки на приватные файлы, коды доступа, IP принтера или серийные номера.

## Различаем форматы

| Формат | Назначение | Можно сразу печатать? |
| --- | --- | --- |
| `.scad`, `.py`, `.step`, `.blend` | Исходник модели | Нет |
| `.stl`, обычный `.3mf` | Геометрия | Нет, нужна нарезка |
| `.gcode.3mf` с проверенными G-code и профилем | Печатное задание | Только после отдельного разрешения на старт |
| `.zip` | Контейнер исходников | Нет |

Проверка локальных импортированных файлов: `python -m pytest -q tests/test_printing3d_asset_catalog.py`.
