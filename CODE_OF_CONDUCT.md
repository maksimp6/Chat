# Code of Conduct

## Our standard

Alice Pro aims to be a practical, welcoming open-source project. Contributors are expected to communicate respectfully, focus on the work, and assume good faith while still discussing technical disagreements directly.

Unacceptable behavior includes harassment, threats, discrimination, doxxing, deliberately exposing private information, or knowingly introducing malicious code or secrets.

## Enforcement

Project maintainers may remove comments, close issues or PRs, or restrict participation when behavior violates this code.

For sensitive conduct concerns, contact the repository maintainer privately through GitHub rather than opening a public issue.

## Scope

This code applies to project spaces and project-related interactions where a contributor is representing or participating in Alice Pro.
